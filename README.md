# Озончик — подготовлено для Railway

Этот проект использует Python 3.12, SQLite и простой HTTP-сервер. Зависимостей pip нет.

## Публикация с iPhone

1. Распакуйте ZIP в приложение «Файлы».
2. Создайте репозиторий GitHub, например `ozonchik`, и загрузите **содержимое** папки проекта в корень репозитория: `catalog.py`, `index.html`, `legacy_ozonchik.html`, `Dockerfile`, `railway.json`, `.gitignore`, `.dockerignore`. На мобильном GitHub удобно добавлять файлы по одному через **Add file → Upload files** в браузере с режимом «Версия для компьютера», если мобильная страница скрывает загрузку.
3. Откройте https://railway.com/new → **Deploy from GitHub repo** → выберите репозиторий. Разрешите Railway доступ к нему.
4. В Railway откройте сервис → **Settings → Volumes → Add Volume** (или через canvas), mount path **`/data`**. **Сделайте это до первого импорта**.
5. В **Settings → Networking** нажмите **Generate Domain**. Railway задаёт переменную `PORT` автоматически, сервер её читает. Откройте выданный HTTPS-адрес на iPhone.
6. Проверьте `https://ВАШ-ДОМЕН/health` — должен вернуться `{"ok":true,"service":"ozonchik"}`. `https://ВАШ-ДОМЕН/api/stats` покажет число записей (изначально 0).
7. Старый демонстрационный сайт доступен по адресу `/legacy`; его 542 позиции не являются импортированным открытым каталогом.

## Наполнение реальными товарами

Официальные массовые выгрузки: https://world.openfoodfacts.org/data . Для первого запуска скачайте CSV/TSV или `.gz` и импортируйте **локально** командой:

```sh
python catalog.py import /path/to/openfoodfacts.csv.gz --source food --limit 10000
python catalog.py stats
```

`--limit 10000` означает **просмотреть** 10 000 строк, а не гарантированно получить 10 000 товаров: часть не имеет фото/названия. Для массового импорта не загружайте выгрузку в GitHub. Чтобы наполнить уже размещённую базу, загрузите CSV на том Railway (например, через Railway CLI / временную административную процедуру с ограниченным доступом), затем выполните `python /app/catalog.py import /data/имя.csv.gz --source food`. Не добавляйте публичный URL импорта без авторизации.

Для теста на компьютере: `python catalog.py serve --port 8765`, открыть http://localhost:8765.

## Хранение и ограничения

- SQLite хранится в `/data/catalog.sqlite3` на Railway и рядом с кодом при локальном запуске. Volume `/data` **обязателен**, иначе данные исчезнут при новом развёртывании.
- Важно: браузерный баланс/корзина/заказы хранятся **только в localStorage данного браузера** и не синхронизируются между устройствами.
- Каталог сначала пустой: реальный массовый экспорт не включён.
- Условия использования данных: Open Food Facts / Open Beauty Facts — ODbL, фотографии CC BY-SA; соблюдайте атрибуцию и share-alike, учитывайте права третьих лиц.
- Для 100 000–1 000 000 записей нужны PostgreSQL, полнотекстовый поиск и отдельная архитектура импорта.
- Не запускайте несколько реплик сервера с общей SQLite-базой; на первом этапе достаточно одной.
- Сведения о ценах Railway проверяйте перед оплатой: https://railway.com/pricing .
